# Симулятор молитв для Honkai: Star Rail
Симулятор Honkai: Star Rail для большого количества круток. Переведен на русский и английский языки, работает с версией HSR 2.4 и выше (релиз Моцзэ).

## Как это работает

### 1. Решите, нужно ли отслеживать определенных персонажей
Приложение может отслеживать созвездия определенных 4-звездочных персонажей. Вы можете выбрать трех персонажей из списка на выбранном языке. Список можно открыть, введя `0` в поле имени. Остальные персонажи будут считаться небаннерными и будут иметь свои шансы выпадения. Созвездия записываются в файл `4starconst.txt` и устанавливаются равными 0. Файл можно изменять вручную. Выбор персонажей доступен, если в соответствующем поле после ввода созвездий 5-звездочного персонажа ввести `1`.

### 2. Введите конфигурацию
Введите количество доступных круток, сколько откручено для 4- и 5-звездочных персонажей, количество созвездий 5-звездочных персонажей, имена определенных баннерных 4-звездочных персонажей (если вы выбрали их отслеживание) и их количество созвездий, доступное количество круток в магазине за звездную пыль, а также доступное количество звездной пыли и звездного блеска на начало симуляции. Если указаны некорректные данные, соответствующий параметр получает значение по умолчанию: отсутствие персонажа для персонажей и `0` для всех остальных параметров.

### 3. Посмотрите результат
После симуляции отображается следующая информация:
1. Количество круток с учетом конвертации звездного блеска и звездной пыли
2. Гарантия для 4- и 5-звездочных персонажей
3. Количество созвездий 4- и 5-звездочных персонажей
4. Общее количество полученных звездного блеска и звездной пыли
5. Количество дополнительных круток, приобретенных за звездный блеск и звездную пыль
6. Список созвездий небаннерных 4-звездочных персонажей

## Изменение настроек
Программа использует `.txt`-файлы со всей необходимой информацией, расположенные в папке `data`. С помощью этих файлов можно изменить язык и начальные созвездия 4-звездочных персонажей. **ВНИМАНИЕ:** файлы, отвечающие за созвездия и имена 4-звездочных персонажей, **должны содержать 22 строки**. Удаление или добавление строк может привести к некорректной симуляции. Чтобы установить начальное созвездие для небаннерного 4-звездочного персонажа, найдите номер строки, в которой записано его имя, и замените номер созвездия на соответствующее значение.
